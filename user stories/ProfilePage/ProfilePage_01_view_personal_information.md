# View personal information

**Title:**
_As a user, I want to view my saved name, username, age, and country on my profile page, so that I can see the details I provided during registration._

**Acceptance Criteria:**
1. The user can view their saved name.
2. The user can view their username.
3. The user can view their age.
4. The user can view their country.

**Priority:** _Low_

**Story Points:** _5_

**Notes:**
- The user must be logged in.
