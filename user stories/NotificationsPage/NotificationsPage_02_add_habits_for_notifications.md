# User Story Template

**Title:**
_As a user, I want to select specific habits to receive notifications for, so that I only get reminders for the habits I am actively working on._

**Acceptance Criteria:**
1. The user can select specific habits to receive notifications for.
2. The user only gets reminders for the habits they selected.

**Priority:** _Low_

**Story Points:** _5_

**Notes:**
- The user must be logged in.
- For the user to receive notifications, the user needs to have granted permission to the app to send notifications.
