# Display weekly progress

**Title:**
_As a user, I want to see my daily progress for each habit on the homepage, so that I can easily monitor my progress._

**Acceptance Criteria:**
1. The user sees their personal weekly progress daily for each habit on the homepage.

**Priority:** _Medium_

**Story Points:** _8_

**Notes:**
- The user must be logged in.
- Only the user's own daily/weekly progress is shown.
