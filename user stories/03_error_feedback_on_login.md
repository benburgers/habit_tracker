# Error feedback on login

**Title:**
_As a user, I want to receive a message if I enter the wrong username or password so that I know that my login attempt was unsuccessful._

**Acceptance Criteria:**
1. The user receives the message only if the login attempt was unsuccessful.
2. The message the user receives is clear, concise, unambiguous, and informs the user.

**Priority:** _High_

**Story Points:** _1_

**Notes:**
- The error feedback must follow UX/UI design principles.
- Due to security constraints, the error feedback must not distinguish between non-existing accounts and invalid credentials.
