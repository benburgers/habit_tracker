# Sign out from menu

**Title:**
_As a user, I want to sign out of my account using an option in the menu, so that I can securely log out when I'm finished using the app._

**Acceptance Criteria:**
1. When the user logs out, any caches with secure data are empty.
2. When the user logs out, they no longer have access to features that are only accessible to logged in users.

**Priority:** _High_

**Story Points:** _2_

**Notes:**
- The user must be logged in.
