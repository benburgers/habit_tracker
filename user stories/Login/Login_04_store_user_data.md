# Store user data

**Title:**
_As a user, I want my user details to be saved in local storage, so that data persists between app sessions._

**Acceptance Criteria:**
1. User data is stored in local storage.
2. If present, user data is loaded back from local storage in a new session.

**Priority:** _Low_

**Story Points:** _5_

**Notes:**
- The user must be logged in.
