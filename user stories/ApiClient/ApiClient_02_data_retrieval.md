# API data retrieval

**Title:**
_As a user, I want my persisted data to be retrieved from an external API, so that I can access the data I persisted earlier and continue in a later session._

**Acceptance Criteria:**
1. When persisted data is required, it is retrieved from an external API.

**Priority:** _High_

**Story Points:** _8_

**Notes:**
- The user must be logged in, unless the data involves registration or publicly available data.
