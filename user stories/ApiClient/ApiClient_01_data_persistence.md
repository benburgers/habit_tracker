# API data persistence

**Title:**
_As a user, I want my persisted data to be saved securely via an external API, so that my data is saved and can be retrieved later._

**Acceptance Criteria:**
1. When data is persisted, the data is sent to an external API that saves the data.

**Priority:** _High_

**Story Points:** _8_

**Notes:**
- The user must be logged in, unless the data involves registration or publicly available data.
