# Account registration

**Title:**
_As a user, I want to register with my name, username, age, and country so that I can create an account and access the habit tracking features._

**Acceptance Criteria:**
1. The user is registered with their name, username, age, and country.
2. The user has an account.
3. The user can access the habit tracking features.

**Priority:** _High_

**Story Points:** _8_

**Notes:**
- The registration is sent through a secure connection.
- The registration takes place in the app.
