# Update name in header

**Title:**
_As a user, I want my updated name to be displayed in the app's header after I change it in the profile, so that my changes are immediately visible._

**Acceptance Criteria:**
1. The user sees the updated name in the app's header after they changed it in their profile.

**Priority:** _Low_

**Story Points:** _1_

**Notes:**
- The user must be logged in.
