# Edit personal information

**Title:**
_As a user, I want to update my name, username, age, and country on my profile page, so that I can keep my information up to date._

**Acceptance Criteria:**
1. The user can update their name.
2. The user can update their username.
3. The user can update their age.
4. The user can update their country.

**Priority:** _Low_

**Story Points:** _8_

**Notes:**
- The user must be logged in.
