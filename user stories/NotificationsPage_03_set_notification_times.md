# User Story Template

**Title:**
_As a user, I want to have the option to receive notifications three times a day (morning, afternoon, evening), so that I get timely reminders throughout the day to complete my habits._

**Acceptance Criteria:**
1. The user has the option to receive notifications three times a day.
2. The user gets notifications three times a day if the user selected this option.

**Priority:** _Low_

**Story Points:** _5_

**Notes:**
- The user must be logged in.
- For the user to receive notifications, the user needs to have granted permission to the app to send notifications.
